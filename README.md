# Headphones website

A headphone website using the Bento box design trend in HTML, CSS, and JavaScript. This project features a clean and simple design with an emphasis on easy navigation, ideal for showcasing headphones or audio products.

![preview](https://github.com/user-attachments/assets/5ed25837-2a33-407b-a1a1-2da70e2d545c)

## Features

- 🎨 **Bento Box Design**: A modern and minimalist design that enhances user experience through a grid-based layout.
- ⚡ **CSS Animation**: Page launch animations using RevealScroll to provide a smooth transition effect.
- 🖱️ **Swiper Slider**: Interactive product carousel built with Swiper JS for an engaging browsing experience.

## Technologies Used

- **HTML5** for structuring the content.
- **CSS3** for styling and animations.
- **JavaScript** for interactive elements like the Swiper slider.
- **[Swiper JS](https://swiperjs.com/)** for the image and product slider.
- **[Remixicon](https://remixicon.com/)** for social icons.
